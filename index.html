AI Lead Classifier

n8n, Groq API (llama-3.1-8b-instant), Airtable

  • The result (Hot, Warm, or Cold, with reasoning) is written back to the record.
  • It filters on an empty classification field, so no record is processed twice and no API call is wasted.
